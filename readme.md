# 🤖 Jarvis - AI Voice Assistant

A Python-based AI voice assistant designed to interact through natural voice commands and perform tasks using AI, web search, text-to-speech, and automation.

## ✨ Features

- 🎤 Speech recognition
- 🧠 AI-powered responses
- 🌐 Real-time web search
- 🔊 Text-to-speech
- 🖥️ Desktop and web automation
- 👁️ Basic screen/vision capabilities
- 🎨 Image generation support

## 🛠️ Tech Stack

- Python
- Groq
- Cohere
- Edge TTS
- SpeechRecognition
- BeautifulSoup
- Requests
- Pygame

## 🏗️ Architecture

```text
Voice Input
     ↓
Speech Recognition
     ↓
Command Processing
     ↓
AI / Web Search / Automation
     ↓
Response Generation
     ↓
Text-to-Speech
     ↓
Voice Output
